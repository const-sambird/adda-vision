# adda-vision
artefacts for our EDBT 2027 vision paper

---

Hello!

This is the repo for our EDBT paper. There are several related submodules:

* `dina` is the code we used to run the DINA and qDINA comparisons
* `extend-dist` is the code for the DiversityClusterDB algorithm
* `adda` has our program's code
* `adda-cplex` is the optimisation program we use for the CPLEX comparison

Further information (including instructions for running these algorithms) is available there. Thanks!
